# Meroza Kitchen Demo

Original fictional pure-vegetarian restaurant and online-ordering website created for the AJAYNXT portfolio.

## Included
- Original restaurant logo
- Cinematic food hero
- Pure-veg menu catalogue from JavaScript data
- Dish search, filters and sorting
- Product details modal
- Cart and quantity controls
- Delivery / pickup toggle
- Branch selection
- WhatsApp order enquiry
- Table booking
- Catering enquiry
- Offers and bundle add-to-cart
- Loyalty concept
- Order-tracking concept
- Branch finder
- AJAYNXT website-price form
- Auto colour and heading-font changes every 3 seconds
- Manual colour, HEX and font controls
- Colour lock, font lock and lock both
- Light, dark and system modes
- Responsive/mobile actions
- SEO, sitemap, robots, manifest, favicon, 404 and CNAME

## GitHub Pages
Upload all files to repository root, enable GitHub Pages from `main` / root and set the custom domain to `food.ajaynxt.com`.
