# Meroza Kitchen Top-5 Food UX Demo

A complete fictional pure-vegetarian restaurant, ordering, dine-in and catering website created for the AJAYNXT portfolio.

## UX patterns combined

- Location-first ordering
- Delivery and pickup mode
- Sticky menu search and category navigation
- Offers and one-tap combo additions
- Static HTML menu that remains visible if JavaScript fails
- Dish customisation and add-ons
- Cart quantity controls
- Coupon area and transparent demo charges
- Recommended add-on
- WhatsApp checkout enquiry
- Table booking and group dining
- Party and catering enquiry
- Loyalty and reorder concept
- Order tracking concept
- Branch search and branch-specific ordering
- Mobile bottom actions
- Full appearance customizer

## Reliability fixes

- No section uses `opacity: 0` as its default state.
- Menu items are real HTML, not generated only by JavaScript.
- Remote image failure leaves designed colour fallbacks instead of blank sections.
- JavaScript is loaded with `defer`.
- Core sections remain readable with JavaScript disabled.
- Reduced-motion preference disables automatic colour and font rotation.

## Appearance controls

- Automatic colour rotation every 3 seconds
- Automatic heading-font rotation every 3 seconds
- Manual colour picker and HEX input
- Manual heading font
- Colour lock, font lock and lock both
- Light, dark and system modes

## GitHub Pages

1. Extract the ZIP.
2. Upload the files and `assets` folder to the repository root.
3. Enable GitHub Pages from `main` branch and `/root`.
4. Set the custom domain to `food.ajaynxt.com`.

## DNS

- Type: CNAME
- Name: food
- Value: ajaynxt.github.io
- TTL: 30 minutes or default
